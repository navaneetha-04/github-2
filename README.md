# EST-1 Algorithms and Problem Solving

A structured, syllabus-aligned C++14 repository for **EST-1: Algorithms and Problem Solving**, Every topic across **UNIT 3** and **UNITS 4 & 5** is organized into dedicated topic folders and self-contained problem modules with beginner-friendly explanations, step-by-step procedures, complexity analyses, and C++14 source files.

## Standardized 11-Point Problem Folder Structure

Every problem folder inside `Questions-and-Solutions/` contains `solution.cpp` (or `solution.c` for uploaded console visualizers) and a `README.md` with all 11 required sections:

1. **Problem Title**
2. **HackerRank Problem Link**
3. **Problem Statement Summary**
4. **Objective**
5. **Algorithm**
6. **Step-by-Step Procedure**
7. **C++ Source Code**
8. **Sample Input and Output**
9. **Time Complexity**
10. **Auxiliary Space Complexity**
11. **Explanation of the Program**

## Compilation & Execution Instructions

Compile any C++14 solution using `g++`:

```bash
g++ -std=c++14 -O2 solution.cpp -o solution
./solution < input.txt
```

Compile the Windows console visualizers (`solution.c`) on Windows (MinGW/GCC):

```bash
gcc -std=c11 solution.c -o visualizer.exe
./visualizer.exe
```
